As a **Senior Computer Vision Engineer at Catapult / IMPECT**, I lead the technical direction of a
real-time tracking pipeline that turns sensor data into motion recognition and performance metrics.

## Technical Scope

- Train, optimize, and deploy real-time segmentation and classification models.
- Run efficient inference on embedded hardware and edge accelerators.
- Extend the tracking system to support new movements, metrics, and analysis workflows.
- Evaluate tracking accuracy and build quality metrics that improve system reliability.

## Engineering Leadership

- Set technical direction across the computer-vision and tracking pipeline.
- Manage and mentor a small engineering team while remaining hands-on with system design and development.
